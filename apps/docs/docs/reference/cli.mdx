---
title: CLI
description: npx @nuniapp/cli prints a project ID and the exact install steps for your project.
sidebar:
  order: 2
---

```bash
npx @nuniapp/cli init           # project ID + install steps for this framework
npx @nuniapp/cli init --json    # the same as JSON, for agents
npx @nuniapp/cli init --id nuni_...   # reuse an existing ID
npx @nuniapp/cli prompt         # the ready-made agent prompt
npx @nuniapp/cli id             # just a new project ID
```

`init` never edits your files. It detects Next.js (App and Pages Router), React with Vite, React Router and Remix, TanStack Start, Gatsby, Vue, Nuxt, Svelte, SvelteKit, Astro, Angular and plain HTML, plus npm, pnpm, yarn and bun.
