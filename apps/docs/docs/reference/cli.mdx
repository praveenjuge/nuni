## Set up

```bash
npx @nuniapp/cli@latest init                 # project ID + install steps for this framework
npx @nuniapp/cli@latest init --json          # the same as JSON, for agents
npx @nuniapp/cli@latest init --id nuni_...   # reuse an existing ID
npx @nuniapp/cli@latest prompt               # the ready-made agent prompt
npx @nuniapp/cli@latest id                   # just a new project ID
```

`init` never edits your files. It detects Next.js (App and Pages Router), React with Vite, React Router and Remix, TanStack Start, Gatsby, Vue, Nuxt, Svelte, SvelteKit, Astro, Angular and plain HTML, plus npm, pnpm, yarn and bun.

## Comments

```bash
npx @nuniapp/cli@latest login                         # approve this terminal in the dashboard
npx @nuniapp/cli@latest whoami                        # who you are signed in as
npx @nuniapp/cli@latest comments [--status open|resolved] [--page /path] [--limit 20]
npx @nuniapp/cli@latest comment <id> [--save-screenshot <dir>]
npx @nuniapp/cli@latest reply <id> "message"
npx @nuniapp/cli@latest resolve <id> [--note "what changed"]
npx @nuniapp/cli@latest reopen <id>
npx @nuniapp/cli@latest logout
npx @nuniapp/cli@latest mcp                           # MCP server on stdio
```

These commands work on one project: `--project nuni_...`, then `$NUNI_PROJECT`, then the `nuni_` ID found in your code. `$NUNI_TOKEN` overrides the saved session, for CI. Every command takes `--json`. See [Coding agents](/guides/agents) for the MCP setup.
