## Keyboard

| Key | Action |
| --- | --- |
| <kbd>C</kbd> | Start or stop adding a comment |
| <kbd>Esc</kbd> | Cancel, close the comment, then the panel |
| <kbd>Cmd</kbd> + <kbd>Enter</kbd> | Post the comment |
