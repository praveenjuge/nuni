Sign in at [/dashboard](/dashboard) with GitHub. You'll see every project you claimed, with open and total comment counts that update live.

In a project you can:

- Switch between **Open** and **Resolved** comments.
- Filter by page, by environment, or search the text.
- **Jump to comment**: opens the page on the environment where the comment was left, with the comment focused.
- See the **screenshot** and open **Page context**: console errors, failed requests, the element's markup and styles, and the browser.
- **Copy for agent**: copies the comment with all of its context as a ready-made task for Claude Code, Codex, Cursor and other coding agents.
- Read a comment's **replies** and reply as the owner (your replies show an **Owner** badge on the site).
- **Resolve**, **Reopen** or **Delete** comments, one at a time or many at once: tick the comments (or **Select all**) and use the bar at the bottom.
- Copy the project's agent setup prompt.

## Settings

Open **Settings** on a project to:

- **Rename** it. The name is only shown in the dashboard.
- See the **signed-in devices**: browsers where you act as the owner in the widget, and terminals where the [CLI or MCP server](/guides/agents) is signed in. Sign one out, or **Sign out everywhere**.
- **Transfer** it to someone else. Make a link and send it to them; when they open it signed in and accept, they become the owner, and your devices are signed out. The link works once, for 7 days, and making a new one cancels the old one.
- **Release** it. You stop being the owner and anyone can claim it again from the widget. Comments stay.
- **Delete** it, with every comment, reply and screenshot. Type the project name to confirm. This can't be undone. If the widget is still on your site, the next comment starts a new, empty, unclaimed project with the same ID.
