Nuni adds Figma-style comments to your **real, running website**. Anyone who can open the site can click an element and leave a comment. The pin stays on that element, even as the page changes.

- No commenter accounts. Visitors type a name and comment.
- No API keys or dashboard setup. One public project ID in your code.
- Works everywhere you deploy: localhost, preview URLs, staging, production.

## Add Nuni in a couple of minutes

Paste this into your coding agent. It already contains a fresh project ID for your site.

<CopyPrompt />

Prefer doing it by hand? Run `npx @nuniapp/cli@latest init` and follow the [quickstart](/quickstart).

## How it works

<Steps>
  <Step title="Add">Install the package and render it once, globally. The agent prompt does this for you.</Step>
  <Step title="Deploy">Ship to any URL. The same project ID works on every environment.</Step>
  <Step title="Comment">Press <kbd>C</kbd>, click anything, write a comment. The pin appears for everyone, live.</Step>
  <Step title="Claim">Own the site? Open the Nuni panel, choose **Claim Nuni** and sign in with GitHub.</Step>
  <Step title="Resolve">Resolve, reopen and delete comments from the widget or the [dashboard](/dashboard).</Step>
</Steps>
