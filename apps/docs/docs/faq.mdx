<Accordion>
  <AccordionItem title="Do commenters need an account?">
    No. They type their name once and it is remembered in their browser.
  </AccordionItem>
  <AccordionItem title="Where do I find the comments I left?">
    Open the Nuni panel and choose **Yours**. It lists your comments on every
    page of the site, with whether each one is open or resolved, and opens any
    of them where it was left. They are tied to your browser, so another browser
    or device starts empty.
  </AccordionItem>
  <AccordionItem title="Is the project ID a secret?">
    No. It is public and meant to be committed. It only connects comments to
    your site.
  </AccordionItem>
  <AccordionItem title="Will it slow down my site?">
    Nuni loads after the page is idle, renders in a Shadow DOM, and the script
    is about 40 KB gzipped. The screenshot code is a separate file that only
    loads when someone leaves a comment.
  </AccordionItem>
  <AccordionItem title="Can I hide it in production?">
    There is no switch for it. Render the component conditionally if you need
    to, for example only when an env var is set.
  </AccordionItem>
  <AccordionItem title="How do I hand a comment to my coding agent?">
    Open the comment in the widget (as the owner) or in the dashboard and choose
    **Copy for agent**. It copies the comment with its page, element, screenshot
    link, console errors and failed requests as a task you can paste into Claude
    Code, Codex or Cursor. Or let the agent fetch comments itself with the [CLI
    or the MCP server](/guides/agents), and resolve them when it is done.
  </AccordionItem>
  <AccordionItem title="Can I change how it looks or what it says?">
    Yes. Pick the toolbar's corner, your brand color, a light or dark theme, the
    button label and the shortcut key, and replace any of its words for your
    language. See the [options](/reference/options#look-and-language).
  </AccordionItem>
  <AccordionItem title="Can commenters add images or draw on the screenshot?">
    Yes, once the site is claimed. In the comment box, add up to three images
    (pick a file or paste one), or choose **Mark up a screenshot** to draw
    boxes, arrows or lines on the element's screenshot. Unlike the screenshot
    itself, which only the owner sees, these images are shown to everyone who
    can see the comment.
  </AccordionItem>
  <AccordionItem title="What is not there yet?">
    Teams and roles, notifications and GitHub issue sync. The big goal stays the
    same: Nuni comment, exact UI context, coding agent, fix.
  </AccordionItem>
</Accordion>
